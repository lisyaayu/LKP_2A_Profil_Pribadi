LKP 2A - Halaman Profil Pribadi dengan HTML5 & CSS

Isi folder:
- index.html : struktur halaman profil
- style.css  : desain dan tata letak halaman
- assets/    : tempat menyimpan foto profil

Sebelum menjalankan:
1. Masukkan foto milik sendiri ke folder assets.
2. Ubah nama file foto menjadi foto.jpg.
3. Ganti email dan username GitHub pada bagian Kontak di index.html.
4. Buka index.html menggunakan browser.

Bagian yang diterapkan:
- HTML5 semantik: header, nav, main, section, footer
- CSS eksternal
- Flexbox pada navigasi
- CSS Grid pada kartu keahlian
- Hover effect pada tautan dan kartu
